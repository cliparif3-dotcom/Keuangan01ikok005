# Kas Kelas 01IKOK005 — MOODBOARD CK05

Aplikasi web pengelola kas kelas dan dana kolektif seminar (terpisah), dengan ekspor Excel, PNG, dan cetak/PDF.

- Satu file: `index.html` (tanpa build)
- Data tersimpan di browser perangkat (localStorage), tidak tersinkron antar-perangkat
- Excel memakai SheetJS dari cdnjs (perlu internet saat ekspor)

## Deploy ke GitHub Pages
1. Upload semua file ke repositori (branch `main`).
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/`.
